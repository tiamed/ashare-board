# A股通用看盘（TDX 直连）

一个可以在浏览器里直接用的 A 股看盘页：输入**任意**股票 / ETF / 指数 / 可转债代码或名称即可查看，
行情来自 TDX（eltdx）交易所直连，不依赖第三方网页接口。

> **授权提醒**：行情库 `eltdx` 是「非商业学习与研究」授权，**不是开源授权**。
> 本项目面向**个人自部署自用**，请勿部署成对外服务。细节见 [NOTICE.md](NOTICE.md)。

## 启动

需要 Python **3.10+**，其余什么都不用装。

```bash
git clone <这个仓库的地址> ashare-board
cd ashare-board
./run.sh
```

首次运行会自动建 `.venv` 并安装依赖（只有 `eltdx` 一个），之后直接启动。
然后浏览器打开 <http://127.0.0.1:8848>。

换端口：

```bash
./run.sh 8899
```

手动方式（不想用脚本时）：

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python server.py --port 8848
```

### 配置

全部可选，都有默认值。

| 环境变量 | 命令行 | 默认 | 说明 |
|:--|:--|:--|:--|
| `ASHARE_PORT` | `--port` | `8848` | 监听端口 |
| `ASHARE_HOST` | `--host` | `127.0.0.1` | 监听地址；`0.0.0.0` 才能局域网访问 |
| `ASHARE_CONFIG` | `--config` | `./config.json` | 自选列表存放路径 |
| `ASHARE_CACHE_MAX` | — | `400` | 行情缓存条目数上限 |
| `ASHARE_CACHE_MB` | — | `192` | 行情缓存内存上限（MB），小内存机器调小 |

### 关于局域网 / 公网访问

默认只绑 `127.0.0.1`，**只有本机能访问**，这是有意的默认值。

`ASHARE_HOST=0.0.0.0 ./run.sh` 可以让同一局域网内的手机访问。
但请注意：**本服务没有任何登录和鉴权**，凡是能访问到这个端口的人，
都能增删改你的自选列表。所以：

- 家里内网自用 → 可以
- 挂到公网 / 有公网 IP 的服务器 → **不要**，除非你自己在前面加了反向代理和认证

## 数据与实现

- 数据源：`eltdx`（TDX 协议），实时快照、分时、K 线、排行、市场统计均为交易所直连数据。
- 后端：Python 标准库 `ThreadingHTTPServer`，无额外 Web 框架依赖。
- 前端：原生 JS + 本地 ECharts（`static/vendor/echarts.min.js`）；数字使用本地 IBM Plex Mono，无 CDN 依赖。
- 各用途独立 TDX 连接，互不阻塞；接口带 2.5–15 秒 TTL 缓存，避免频繁打交易所。
- 缓存有硬上限（默认 400 条 / 192MB，LRU 淘汰），逛再多的股票也不会把内存吃满。
- 静态资源走 gzip + ETag（命中 304），首屏约 390KB，其中 ECharts 占 334KB。
- HTTP/1.1 keep-alive；页面每 3–5 秒轮询一次，单标签页约 60 请求/分钟。
- 实测（4 核开发机）：单实例在 40 个并发浏览时 p95 约 65ms，占用不到 10% 单核。

## 主要接口

```
GET  /api/overview            指数 + 市场宽度
GET  /api/search?q=茅台       代码/名称搜索
GET  /api/lookup?code=600519  代码解析
GET  /api/quote?code=sh600519 单只快照
GET  /api/minute?code=...     当日分时
GET  /api/kline?code=...&period=day|week|month&count=240
GET  /api/performance?code=...  阶段涨跌幅（5/10/20/60/120/250日、年初至今）
GET  /api/auction?code=...      开盘/收盘集合竞价 + 竞价明细
GET  /api/quotes?codes=...      批量快照（盯盘轮询）
GET  /api/rank?sort=pct|drop|amount|speed
GET  /api/watchlist           自选列表
POST /api/watchlist           {"code":"600519"}
POST /api/watchlist/reorder   {"codes":["sh600519","sz000001"]}   自选排序
DELETE /api/watchlist?code=sh600519
```

## 历史数据有多深

TDX 返回的是完整历史，不是只到某一天：

| 标的 | 最早 | 根数（日K） |
|:--|:--|:--|
| 上证指数 sh000001 | 1990-12-19 | 8757 |
| 贵州茅台 sh600519 | 2001-08-27 | 6036 |
| 科创半导ETF sh588170 | 2025-04-08（上市日） | 384 |

K 线默认只显示最近 160 根，拖动底部滑块或滚轮缩放即可回看；「全部」会加载上市以来全部数据。
前复权在极长历史 + 大额分红下可能出现负价，此时后端自动退回不复权，图上会标注「不复权」。

## 已知限制

- TDX 返回的证券名称最长 8 个汉字，部分 ETF 会显示为截断名（如“科创半导体ETF华”）。
- 指数分时的“均价”字段量纲与个股不同，页面已改为按分钟量价自算。
- 非交易时段行情静止；页面仍可查看最近一个交易日的分时/K 线。
- 首次打开需要 1–3 秒建立 TDX 连接并加载代码表（约 1 万条）。
- 盯盘提醒存在浏览器 localStorage，按设备/域名各自独立；页面需保持打开（后台标签页的定时器可能被浏览器节流到约 1 分钟）。
- 系统通知需要 HTTPS 或 localhost，并在页面右上角「盯盘提醒」里手动授权；iOS 需添加到主屏幕后才支持 Web 通知。
- **没有登录和多用户**：自选列表是单实例单份（`config.json`），天然是「一个人一台机器」的模型。
- **没有鉴权**：任何能访问端口的人都能改自选。公网部署必须自己加反向代理和认证。
- 行情库 `eltdx` 为非商业授权，仅限个人自用，不可用于商业/生产服务（见 [NOTICE.md](NOTICE.md)）。
